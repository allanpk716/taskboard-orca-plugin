# 任务：工单板 Orca 插件面板重设计原型（3 个候选）

你是资深产品设计师 + 前端工程师。为一个 Orca 桌面客户端的侧边栏插件面板做重设计原型，产出 3 个候选方案的独立 HTML 页面，供用户在手机上对比拍板。

## 第一步：读上下文（必读）

- `src/panel.tsx` —— 当前面板布局，是被重设计的对象
- `src/mock.ts` —— mock 数据的真实形状和文案（工单号、原因标签、时间等，直接复用它的数据风格）
- `docs/design.md` —— 产品定位和已拍板的决定

## 背景：当前版本的问题（重设计要解决这些）

1. 概览区 7 行混排：前 4 行统计用灰数字、后 3 行收件箱原因分组用圆徽章，同列两种样式；「新指派给你 2」这类**待办**和「收件箱 5」这类**统计**混排，没有优先级
2. 信息三重重复：概览原因分组 ↔ 通知行的原因标签 ↔ 逐条「未读」文字 ↔ 顶部「通知未读 3」
3. 层级倒置：「全部已读」白字比小节标题「通知」还抢眼
4. 通知行每条 3 行文字 + 按钮，太挤；「20261120-001 · 」工单号占宽，标题刚开头就被截断
5. 无信息量的 label（如「概览计数」）占行

## 面板要承载的信息（不可增删语义，只能取舍组织）

- 头部：标题「工单板」、平台地址、菜单入口（更改地址 / 断开连接）
- 概览统计：协作中（未读数/总数）、在等他（数）、通知未读（数）
- 收件箱（= 轮到当前用户处理的工单，按原因分组：新指派、已交付待验收、指派人回复待答复等），每条：工单号、标题、原因、等了多久、「在浏览器打开」
- 通知列表（最近若干条）：工单号+标题（或纯文本如备份失败通知）、原因、相对时间、已读/未读、「打开」

## 三个候选方案（按此执行，不要自行换成别的方向）

### variant-a.html —— 待办优先（激进取舍）

- 顶部一行紧凑状态条：连接正常的小圆点 + 通知未读数（有未读才显示）
- 主体直接是「轮到你处理」：收件箱条目列表，每条两行——第一行工单号（弱化小字）+ 标题，第二行原因徽章 + 等了多久 + 打开按钮；用原因做小分组标题，组内条目按等了多久排
- 统计（协作中/在等他）压到页面底部一行两格的次要信息条
- 通知不逐条列出：一行摘要「3 条未读通知」+ 展开箭头，展开后是两行式紧凑列表（点标题整行可打开）

### variant-b.html —— 现状重构（保守改良）

- 保持 概览 → 通知 → 收件箱 三段顺序，但每段重构：
- 概览：顶部一行三格数字条（协作中未读 / 在等他 / 通知未读，数字大、标签小、有未读的格子用强调色数字）；下面「待办」小节只列收件箱原因 + 数字（如「新指派 ×2」「待验收 ×2」），视觉上是可扫读的徽章行而非键值对
- 通知行压成两行：第一行标题（未读的加粗/亮色，已读的弱化），第二行原因 · 相对时间；未读用左侧 2~3px 强调色竖条表达，不用「未读」二字；去掉每行的铃铛图标和独立按钮（整行可点）
- 「全部已读」放在「通知」小节标题同一行右侧，弱化为文字链接
- 收件箱行：工单号放第二行弱化小字，第一行留给标题；「在浏览器打开」缩短为图标按钮

### variant-c.html —— 分段标签（导航结构）

- 顶部固定区：标题行（工单板 + 地址合并为一行，地址 truncate）+ 三格统计数字条
- 其下两个 tab：「收件箱 (5)」和「通知 (3)」，切换显示对应列表（默认收件箱 tab）
- 收件箱 tab：两行式条目（标题 + 原因·等了多久·打开），按原因分组
- 通知 tab：两行式条目（标题 + 原因·时间），未读用强调色标题，行尾小圆点；顶部「全部已读」文字链接
- tab 切换用少量 vanilla JS 即可

## 视觉与工程约束（三个页面共同遵守）

- 模拟 Orca 桌面客户端观感：深色主题，页面背景 #101012 左右，卡片 #1a1a1d~#1e1e21 圆角 10~12px，主文字 #ececf1，次要文字 #9a9aa3，强调色用一种偏蓝（#4c8dff 附近）即可，不要渐变不要花哨
- 窄栏形态：内容最大宽度 390px 居中，两侧 12~16px 边距；按手机视口 390×844 设计，不允许横向滚动
- 每页一个自包含 HTML：内联 CSS，系统字体栈（-apple-system, "PingFang SC", sans-serif），不引外部资源、不用框架；少量 vanilla JS 允许（tab 切换、展开折叠）
- 假数据编 8~12 条工单/通知，覆盖多种原因（新指派、已交付、指派人回复、备份失败等）、已读+未读混合、时间从几分钟到几天；工单号风格 20261120-001
- 严格禁止：手机壳/桌面窗口外框、用 ?variant= 查询参数切换方案、任何外链 CDN
- 三个文件写到 `mock/variant-a.html`、`mock/variant-b.html`、`mock/variant-c.html`
